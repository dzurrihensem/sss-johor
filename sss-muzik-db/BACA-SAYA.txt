PEMARKAHAN SSS MUZIK - VERSI PANGKALAN DATA (NETLIFY)
=====================================================

Isi folder:
  public/                    -> laman sistem (index.html, ikon, manifest)
  netlify/functions/api.mjs  -> API pangkalan data (Netlify Blobs)
  netlify.toml, package.json -> tetapan Netlify (jangan ubah)

PENTING: Versi ini TIDAK boleh diupload melalui Netlify Drop (drag & drop),
kerana Drop tidak menyokong Functions. Guna cara GitHub di bawah.

CARA 1 - GITHUB (tanpa pasang apa-apa)
1. Daftar / log masuk di github.com.
2. Klik "+" > New repository. Nama: sss-muzik. Pilih PRIVATE. Klik Create repository.
3. Klik pautan "uploading an existing file".
4. Ekstrak zip ini. Buka folder sss-muzik-db, pilih SEMUA isinya
   (public, netlify, netlify.toml, package.json, BACA-SAYA.txt) dan seret ke halaman GitHub.
   Klik "Commit changes".
5. Di app.netlify.com: Add new site > Import an existing project > GitHub.
   Benarkan akses, pilih repo sss-muzik, klik Deploy. (Tetapan dibaca automatik.)
6. Tetapkan kod akses:
   Site configuration > Environment variables > Add a variable
     Key  : ACCESS_CODE
     Value: (kod pilihan anda, contoh SSM-Muzik#2025 - minimum 8 aksara)
   Kemudian Deploys > Trigger deploy > Deploy site.
7. Buka pautan .netlify.app, masukkan kod akses. Siap.

CARA 2 - NETLIFY CLI (jika komputer ada Node.js)
  cd sss-muzik-db
  npm install
  npx netlify-cli login
  npx netlify-cli init            (cipta laman baru)
  npx netlify-cli env:set ACCESS_CODE "kod-anda"
  npx netlify-cli deploy --prod

KEMAS KINI SISTEM KEMUDIAN
  Ganti fail di GitHub (Add file > Upload files). Netlify deploy semula automatik.
  Data di pangkalan data TIDAK terjejas.

TUKAR KOD AKSES
  Ubah ACCESS_CODE dalam Environment variables > Trigger deploy.
  Semua peranti perlu masukkan kod baru.
